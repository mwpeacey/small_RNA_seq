The custom small RNA annotation was generated by filtering and combining existing GFF3 annotations as described below:

1. The miRNA annotation file was downloaded from miRbase:
wget https://www.mirbase.org/ftp/CURRENT/genomes/mmu.gff3

2. Primary miRNAs were removed to leave only mature miRNAs: 
grep -v miRNA_primary_transcript mmu.gff3 > mm10_miRNA.gff3

3. The GFF3 file containing mature miRNAs was converted to a bed file.
agat_convert_sp_gff2bed.pl --gff mm10_miRNA.gff3 -o mm10_miRNA.bed

4. The miRNA bed file was sorted by genome coordinates.
sort -k1,1 -k2,2n mm10_miRNA.bed > mm10_miRNA.sorted.bed

5. The fasta of mature miRNAs was extracted using bedtools (script "bed_to_fasta.sh")
bedtools getfasta \
    -fi ${GENOME} \
    -bed ${BED} \
    -fo ${FASTA} \
    -nameOnly -s
